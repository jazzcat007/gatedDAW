# The Engine Under the Feathers

Metal-Duck Studio runs on gatedDAW, an open-source audio engine and workstation. You are free to inspect it, learn from it, fork it, and build on top of it.

## The code

The full source lives on [GitHub](https://github.com/jazzcat007/gatedDAW). You can run it yourself, study how the audio engine and devices work, or contribute fixes and features.

## Extend it

gatedDAW ships with an SDK and a plugin model, so you can build your own devices and extensions on top of the studio.
